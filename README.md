# Los prompts con los que Claude hizo «La reina del hielo y yo»

Página regalo del CTA **ESTRATEGIA** (@soydiegoosorio): los prompts del video «La reina del hielo y yo», hecho con un clon
de IA por 3,71 dólares, y la estrategia con la que usamos los agentes de IA en los negocios. Una página por video.

Página: https://diegodoc1111.github.io/prompt-reina-hielo/

## Fuentes verificadas
- Comandos de instalación de Claude Code: https://code.claude.com/docs/en/setup
- Higgsfield CLI (`npm install -g @higgsfield/cli`, `higgsfield auth login`): el CLI que usamos para este video.
- Costo: 290 créditos de Higgsfield (plan de 115 USD por 9.000 créditos = 1,28 centavos por crédito) = 3,71 USD.
